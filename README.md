What is it?

Like bit.ly. You give a long link, and it gives you a short one.

https://mysite.com/very/long/page?id=123 becomes http://localhost:3000/aB3xZ
When someone opens the short link, the server redirects them to the long link.
Every time someone clicks, the server saves that click (time, browser, device, where they came from).
The owner can see stats: clicks per day, top links, devices.
